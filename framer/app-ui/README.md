# Outdooroots app UI — Framer components

Self-contained Framer code components that reproduce the design of the
Outdooroots React app (`src/`): obsidian `#090A0C` backgrounds, alpine red
`#FF3B30` accent, bold uppercase Plus Jakarta Sans and JetBrains Mono labels.

Each file has no imports from other files, so it can be pasted on its own
(Assets → Code → New file). Every text, image, link and colour is a property
control; cards can be bound to CMS fields.

| File | Use |
| --- | --- |
| `ORNavbar.tsx` | Sticky blurred header with links, CTA and mobile menu |
| `ORHero.tsx` | Full-bleed hero: badge, two-line title, CTAs, stats |
| `ORSectionHeader.tsx` | Eyebrow + uppercase title + optional side text |
| `ORRegionCard.tsx` | Tall photo card for regions / chapters |
| `ORJourneyCard.tsx` | Expedition card with tags, duration, region and action |
| `ORCtaBanner.tsx` | Photo call-to-action banner |
| `ORFooter.tsx` | Footer with two link columns and legal line |
